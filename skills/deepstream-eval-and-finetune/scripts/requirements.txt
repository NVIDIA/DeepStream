# Python dependencies for deepstream-eval-and-finetune (installed into build/.venv_train).
# Release-candidate pins for Python 3.12 inside nvcr.io/nvidia/deepstream:9.1-triton-multiarch; run the GPU validation matrix before signing.
# Install with: bash .claude/skills/deepstream-eval-and-finetune/setup.sh   (creates the venv + builds the C app)
#
# NOTE on torch: the default linux-x86_64 PyPI wheel for torch 2.13.0 bundles a CUDA 13 runtime
# (nvidia-cudnn-cu13 / nccl-cu13 / cusparselt-cu13). It relies on NVIDIA driver compatibility rather
# than the container CUDA toolkit; no special --index-url is needed. VALIDATE THIS EXACT STACK in the
# DeepStream 9.1 release image before signing — this replaces the previous torch 2.6.0 / cu124 pin.
#
# NOTE on versions: torch 2.6.0 and transformers 4.49.0 were pinned here previously and both carried
# HIGH "known vulnerable dependency" advisories that block the NVSkills-Eval Tier-1 gate.
#   - torch: 2.13.0 is the first release with zero open OSV advisories (2.8.0 still carries 8).
#   - transformers: the RCE (GHSA-29pf-2h5f-8g72) is fixed only in 5.3.0 and the
#     model-init arbitrary-code-execution (GHSA-fgcw-684q-jj6r) only in 5.5.0. No 4.x release
#     clears them, so this is necessarily a major bump to the 5.x line.
# transformers 5.x drives the hub/tokenizers/safetensors floors below
# (huggingface-hub>=1.5, tokenizers>=0.22,<=0.23, safetensors>=0.8).
